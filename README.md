# Портфолио — Arcnosixa

Статический сайт-портфолио: тёмная тема, RU/EN переключатель, 3D-сцена в hero,
адаптив, без сборщиков и без внешних зависимостей.

## Открыть

Двойной клик по `index.html` — всё работает с `file://`, ничего запускать не нужно.
three.js лежит в `vendor/` и грузится лениво, поэтому офлайн и `file://` тоже работают.

Для проверки в браузере с корректными шрифтами и кешем:

```bash
python3 -m http.server 4173
# http://localhost:4173
```

## Доступность

- «Skip to content» — первая ссылка в табуляции, ведёт на `<main id="main">`.
- Мобильное меню на `visibility: hidden`, поэтому закрытые ссылки не ловят фокус.
- Иконка бургера, язык и фильтры подписаны через `data-i18n-aria` и
  `data-i18n-aria-label` в разметке; ключи лежат в `I18N.*.a11y`.
- `aria-pressed` у чипов-фильтров, счётчик проектов дублируется в `aria-live`.
- Полоса с ядром помечена `aria-hidden` и не читается скринридерами.
- Без JS страница остаётся читаемой: контент в разметке, меню раскрыто, декоративные
  слои (`no-gl`) скрыты. Тексты подменяются скриптом, но в разметке лежит русский вариант.

## 3D-сцена

`scene3d.js` собирает сцену из процедурных моделей — внешних ассетов нет:

- `core` — икосаэдр с плоскими гранями и лаймовыми рёбрами;
- `shell` — крупнее, синий каркас, вращается против основного;
- два `тороида`-кольца разного наклона;
- три спутника-октаэдра на орбитах;
- поле из 900 точек.

Мышь даёт параллакс, перетаскивание по hero крутит модель с инерцией, скролл
уводит камеру назад. Рендер останавливается, когда hero уходит из кадра или вкладка
неактивна. Если WebGL недоступен или включён `prefers-reduced-motion`, на `<html>`
добавляется `no-gl`, канвас прячется, сайт выглядит как раньше.

## Секция проектов

Между панелью фильтров и сеткой стоит полоса с объектом — «ядром». Состояние ядра
задаёт колесо мыши: прокрутка вверх заряжает его (сжатие, частицы летят к центру,
палитра уходит в лайм), вниз разряжает (расширение, частицы расходятся, палитра в
оранжевый). Через ~0.6 с без колеса энергия плавно спадает и ядро возвращается в
`idle`. Слева внизу — шкала с ромбом-маркером: он уезжает влево на заряде и вправо на
разряде. Рендер идёт, только пока полоса в кадре, скролл на тач-устройствах учитывается
так же. Полоса помечена `aria-hidden` и ничего не сообщает скринридерам; при
`prefers-reduced-motion` рисуется один статичный кадр, состояние меняется только цветом
и положением маркера.

Сверху — панель управления: чипы-фильтры по категориям с бегущим индикатором и
счётчик «показано / всего». Фильтры объявлены как группа кнопок с `aria-pressed`,
счётчик дублируется в `aria-live`-области для скринридеров.

Дальше — бенто-сетка: главный проект раскрыт и занимает всю ширину, остальные свёрнуты
в компактные карточки. Кнопка «Подробнее» раскрывает описание, пункты и ссылки прямо
в карточке: она растягивается на всю строку, а соседние карточки съезжают вверх
(FLIP-анимация). Работает как аккордеон — открыта одна карточка, `Esc` сворачивает,
стрелки `↑`/`↓` переключают фокус между карточками, `Home`/`End` — к краям.

При смене фильтра карточки не перерисовываются, а плавно переезжают на новые места:
сначала гаснут уходящие, потом FLIP двигает оставшиеся, новые въезжают снизу.
Если Web Animations API недоступен или включён `prefers-reduced-motion`, всё
переключается мгновенно.

Лаборатория вынесена в «консоль»: строки-строки вывода с `›`, тегом стека справа и
мигающим курсором в конце.

Категории для фильтра задаются один раз в `PROJECT_CATS` в начале `app.js`:
`web`, `mobile`, `ai`. Новый фильтр добавляется одной строкой в `WORK_FILTERS`
(значение + i18n-ключ) и блоком в словаре.

## Анимации

- Интро hero: посимвольный stagger заголовка, выезд акцентной строки.
- Reveal-секции с задержками, заголовки проявляются из blur.
- 3D-наклон карточек с бликом, который следует за курсором.
- Магнитные кнопки и ссылки, `scale` по нажатию.
- Курсорное свечение в hero, параллакс текста при скролле.
- Топбар прячется при скролле вниз и возвращается вверх.
- Линия «Пути» заполняется по мере прокрутки, счётчики в «Обо мне» считают числа.
- Плавный кроссфейд при смене языка.
- В карточках проектов: акцентная линия рисуется по верхней кромке, по диагонали
  проходит блик, глоу за курсором берёт цвет проекта, метрики прижаты к низу.

Всё уважает `prefers-reduced-motion`: анимации отключаются, канвас и курсорное
свечение не рисуются, текст и линии остаются статичными.

## Где править контент

Весь контент лежит в одном месте — в начале `app.js`:

- `I18N.ru` / `I18N.en` — тексты интерфейса (подписи, навыки, контакты).
- `PROJECTS` — проекты одним списком на оба языка: поле с суффиксом `En` — английский
  вариант, без него — русский, метрика задаётся тройкой `[значение, ru, en]`.
  `localizeProjects()` собирает из него `I18N.ru.projectsList` и `I18N.en.projectsList`,
  так что тексты не расходятся между языками.
- `I18N[lang].labsList` — маленькие и учебные проекты.
- `I18N[lang].timelineList` — блок «Путь».
- `I18N[lang].contactsList` — контакты: `label`, `value`, `href`, `copy`.

Чтобы добавить проект, скопируй объект в `PROJECTS` и поменяй поля. Featured-проект
(открыт по умолчанию и занимает всю ширину) помечается полем `featured: true`, цвет
акцента — `accent`, категории для фильтра — в `PROJECT_CATS`.

Статичные подписи в `index.html` помечены `data-i18n="ключ"`: текст берётся из словаря,
в разметке нужен только ключ. Заголовок hero разбивается на символы автоматически —
при смене языка разбивка пересобирается.

## Что заменить перед публикацией

- Ссылки на проекты в `PROJECTS.links`: у Ciel и ESEP стоят живые сайты, у OSINT Portal —
  публичный репозиторий. У TradingAgents репозиторий приватный, поэтому `links: []` и
  вместо ссылки карточка показывает имя ключа. Пустые `links` — не ошибка, а заглушка.
- Счётчики в `index.html` (`data-count`) — подставь свои цифры. Сейчас стоят `4`
  проекта в портфолио, `4` года коммерческой разработки, `2` языка интерфейса и `3`
  платформы (web, mobile, desktop).
- Число проектов дублируется в hero (`data-count` рядом со счётчиком) и в
  `I18N.*.workStatus` собирается из списка, поэтому руками его править не нужно.
- Ссылка `https://arcnosixa.dev/` в `canonical`, `og:url` и `hreflang` в `index.html`
  заменяется на фактический домен, если он не совпадает с `arcnosixta.github.io`.

Проверено и готово: контакты `t.me/arcnosixta` и `github.com/arcnosixta`,
`title`/`description`/`og` в обоих языках, `og.png`, `robots.txt`, `sitemap.xml`,
`404.html`.

## SEO

В `<head>` уже стоят `canonical`, `description`, Open Graph, Twitter Card и
JSON-LD (`Person`). Русский вариант в разметке, английский подставляет
`applyStaticText()` из `I18N.en.meta.*` — поэтому после переключения языка
`document.title`, `description` и `og:title`/`og:description` меняются вместе с
интерфейсом. Сам `og:url` и `canonical` статичны: язык не меняет адрес страницы.

## Деплой

Папка статическая: подойдут Vercel, Netlify, GitHub Pages, Cloudflare Pages.
Загрузи содержимое репозитория как корень сайта — сборка не требуется.

Для GitHub Pages в репозитории уже есть `.github/workflows/pages.yml`: после пуша в
`main` статика публикуется как сайт. Перед загрузкой workflow подставляет в ссылки на
`styles.css` и скрипты `?v=<коммит>`, поэтому браузер не показывает старые файлы из
кеша после деплоя. Своя версия в `index.html` руками не нужна. Свой домен подключается
там же в Settings → Pages → Custom domain.
